This tiny flower is a fun way to use leftover yarn. Add it to a hat, tote bag, or gift wrapping. This tutorial uses **US stitch names**.

## Stitches you'll need

- **ch** — chain
- **sl st** — slip stitch
- **dc** — double crochet

## The flower pattern

1. Make a magic ring. Keep the ring loose enough to work five petals into it.
2. **Petal 1:** Chain 2, work 2 double crochets into the ring, chain 2, and slip stitch into the ring.
3. Repeat the petal instructions **four more times** (five petals total).
4. Pull the magic ring closed, fasten off, and weave in your ends.

## A little variation

Use one color for all five petals, or try a contrasting center with a small embroidered knot. You can sew the flower onto fabric using its yarn tails.

> Maker's note: If the petals curl too tightly, try going up one hook size.
