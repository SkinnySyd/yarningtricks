# Thread & Petal — Detailed Winter Wanderer Reindeer

This is a REINDEER-ONLY patch, based on the existing published seagull article's
rich editorial approach, designed for your Astro 5 / MDX site.

## Included

- src/content/patterns/winter-wanderer-reindeer.mdx — complete expanded blog tutorial
- src/components/StitchHelp.astro — your existing tutorial links with one reindeer entry
- public/images/finished-projects/winter-wanderer-reindeer.webp — snowy hero
- public/images/tutorials/winter-wanderer-reindeer/reindeer-side.webp — side view
- public/images/tutorials/winter-wanderer-reindeer/reindeer-back.webp — rear view

## Install

1. Extract into the repository root; preserve all folder names.
2. Add the new MDX and three new image files.
3. Replace src/components/StitchHelp.astro (preserves all current entries,
   including the seagull, and adds the reindeer).
4. Run `npm ci`, `npm run check`, and `npm run build`.
5. Commit, push, and check `/patterns/winter-wanderer-reindeer/` on desktop/mobile.
6. Check the gallery, stitch helper links, and print formatting.

The ZIP intentionally does not include or overwrite the seagull MDX or images.
