# Thread & Petal — Meadow Gazelle Amigurumi

This ZIP is a **complete pattern package**, just like the earlier Seahorse delivery. It contains the entire ready-to-publish MDX article and three new image assets in their correct Astro paths. There is NO update script.

## Files

- `src/content/patterns/meadow-gazelle-amigurumi.mdx`
- `public/images/finished-projects/meadow-gazelle-amigurumi.webp`
- `public/images/tutorials/meadow-gazelle-amigurumi/three-quarter-view.webp`
- `public/images/tutorials/meadow-gazelle-amigurumi/face-and-ears.webp`

## Install

1. Revert or remove the earlier gazelle commit first, as planned; make sure the working tree is clean.
2. Extract this ZIP into the root of `crochet-blog-starter` (the folder containing `package.json`). **Merge** the `src` and `public` folders — do NOT delete the existing directories.
3. If Windows asks whether to replace the previous gazelle MDX or any of these three gazelle image files, choose Replace. No other pattern or component is included.
4. Run `npm run check` and `npm run build` (or `npm run dev` for a local preview).
5. Commit and push the four new files to GitHub.

The article is **published by default**, and requires NO `draft` toggle or script.

URL: `https://threadnpetal.com/patterns/meadow-gazelle-amigurumi/`
