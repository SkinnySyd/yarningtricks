# Thread & Petal — free crochet blog starter

A static, responsive crochet learning website built with **Astro 5**, **MDX**, **Tailwind CSS 4**, and **Cloudflare Pages**. You can replace the temporary brand, tutorial examples, and SVG drawings with your own content.

## 1. Run locally

Install Node.js 20.3+ (Node 22 LTS recommended), then run:

```bash
npm install
cp .env.example .env
npm run dev
```

Open the local address printed by Astro (typically `http://localhost:4321`).

**IMPORTANT:** This source archive was created without downloading npm packages in the build environment, so the Astro production build has **not been executed** here. Run `npm run build` after installing dependencies and resolve any dependency changes if the ecosystem has moved on.

## 2. Customize your blog

- Brand/tagline/social link/contact: `src/site-config.ts`.
- Layout, navigation, footer: `src/components/` and `src/layouts/BaseLayout.astro`.
- Site colors and responsive design: `src/styles/global.css`.
- Homepage: `src/pages/index.astro`.
- All patterns / search & category filters: `src/pages/patterns/index.astro`.
- Tutorial layout: `src/pages/patterns/[...slug].astro`.
- Beginner learning page: `src/pages/learn.astro`.
- Blog index: `src/pages/blog/index.astro`.

You can delete/edit the four **example tutorials** under `src/content/patterns/`.

### Create an article

Create e.g. `src/content/patterns/my-first-hat.mdx`:

```mdx
---
title: "My First Crochet Hat"
description: "A cozy hat for beginner crocheters."
publishedDate: 2026-10-27
category: "Accessories"
difficulty: "Beginner"
duration: "2 hours"
image: "/images/my-first-hat.jpg"
imageAlt: "Finished blue crocheted hat on a wooden table"
tags: ["hat", "beginner"]
supplies:
  - "Medium weight yarn"
  - "5 mm crochet hook"
featured: false
---

Write your tested instructions here, with headings, photos, and stitch counts.
```

Upload `my-first-hat.jpg` to `public/images/`. Use **your own original photos**, ideally with strong vertical cover photos for Pinterest. For real Pinterest use, **replace the included decorative illustrated PNG placeholders with your own JPG/PNG/WEBP photos** (and update `image` + `imageAlt` frontmatter). A PNG `social-cover` is included; replace it with branded imagery before launch.

Valid categories: `Stitch guides`, `Home & decor`, `Accessories`, `Amigurumi`.
Valid levels: `Beginner`, `Easy`, `Intermediate`.

When you add an article, the article page, pattern library, journal, related section, RSS feed, and sitemap are generated automatically. For a Pinterest Pin, link directly to the corresponding `/patterns/article-slug/` page.

## 3. Publish free on Cloudflare Pages

1. Create a free GitHub repository; upload this project.
2. In Cloudflare Pages choose **Connect to Git**, select that repository.
3. Build command: `npm run build`.
4. Build output directory: `dist`.
5. Set a `SITE_URL` build environment variable to your real website address, e.g. `https://yourdomain.com` (without trailing slash).
6. Add your own custom domain when ready, and rebuild after `SITE_URL` changes.

You should purchase your domain separately. Cloudflare's free Pages plan can host this site's static output.

## 4. SEO, Pinterest and search

Already included:

- Per-page title, description, canonical URL, Open Graph/Twitter metadata
- BlogPosting structured data for tutorial pages
- Sitemap generated by `@astrojs/sitemap`
- `robots.txt` with sitemap link
- RSS at `/rss.xml`
- Mobile navigation and semantic HTML
- Built-in local title/tag/category filtering on the pattern library page
- Pinterest **Save** link on every article using the current page URL and cover image
- Print-friendly tutorial CSS

There is **no automated Pinterest publishing** because you already generate Pins your own way. Link your Pins to their exact matching tutorial URLs. The sample site uses `<img>` covers; replacing these with original photography is important for actual Pinterest performance.

The initial search is a lightweight in-page filter. For hundreds/thousands of articles, you can later add **Pagefind** as a static search index.

## 5. AdSense setup (ads off by default)

The project includes `src/components/AdSlot.astro` and a global ad script hook in `BaseLayout.astro`. **No Google ad script loads in the default configuration.**

After your site has been approved by AdSense, set your build environment variables (or `.env`) to:

```env
PUBLIC_ENABLE_ADS=true
PUBLIC_ADSENSE_CLIENT=ca-pub-YOUR_PUBLISHER_ID
PUBLIC_ADSENSE_SLOT=YOUR_AD_UNIT_SLOT_ID
```

Ads are inserted in article content/sidebar using the responsive ad unit. Configure an actual AdSense display ad unit, and verify the publisher/slot details in your account. You can alternatively use Auto ads by modifying the layout to load only the approved global Auto ads snippet.

**Privacy/compliance warning:** if your site serves the EEA/UK/Switzerland or other regulated regions, first implement an appropriate consent management solution (including Google's required certified CMP when applicable) *before* enabling advertising. This starter does not implement a consent platform. The Privacy page is a **placeholder**, not a legally complete policy. Fill in your privacy disclosures, cookie choices, identity, and contact details before enabling ads. Add your authorized seller entry in `ads.txt` once AdSense tells you what it should contain.
